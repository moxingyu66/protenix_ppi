# Baseline protocol v0.1

Status: B0a implementation prepared and tested; no biological benchmark trained

## Baseline ladder

### B0a — composition sanity baseline

Use a symmetric feature vector derived from the two canonical sequences:

- mean amino-acid composition;
- absolute composition difference;
- elementwise composition product;
- mean log length;
- absolute log-length difference;
- shorter/longer length ratio.

A standardized, class-balanced logistic regression selects regularization `C` using average precision on the frozen `balanced_explicit_1to1` validation cohort only. Candidate values are fixed to `0.01, 0.1, 1, 10, 100`; ties select the smaller C. The selected model is refit on train plus the complete validation partition and evaluated once on the untouched test set.

The feature map is invariant to swapping protein A and B. This is required because the benchmark treats a physical pair as undirected.

B0a is a pipeline and shortcut sanity check. It is not a strong sequence-model baseline and cannot by itself support a claim that Protenix adds value beyond modern sequence representation learning.

### B0b — strong sequence baseline, required later

Before evaluating hypothesis H2, add frozen embeddings from a predeclared protein language model such as ESM-2. Pool each protein independently, construct a symmetric pair representation, and train the same controlled classifier/ranker. Record the exact model checkpoint, sequence truncation policy, embedding layer, pooling rule, and checksum.

Do not concatenate ordered A/B embeddings without also enforcing swap invariance or augmentation; an arbitrary accession order must not become a feature.

### B1 — Protenix zero-shot

Use only frozen native Protenix structure/confidence outputs under a frozen inference policy. No PPI labels enter this stage.

### B2 — frozen Protenix representation

Train an external classifier on cached, frozen Protenix features. Feature extraction is performed once after the split and backbone locks are frozen.

The executable bundle contract, chain-symmetry requirement, controlled classifier, and interpretation gate are specified in `b2_frozen_protenix_protocol_v0.1.md`.

## Leakage controls

- Input normalized tables must pass `validate_dataset.py` before fitting.
- Hyperparameters are selected on validation only.
- The test partition is loaded for final prediction, never for model selection.
- Feature normalization is fitted inside the training pipeline.
- After selecting C, refitting on train plus validation is permitted because the C3 test protein pool is disjoint from both.
- Every output records source-table hashes, split scheme/fold, feature definition, software versions, seed, and selected hyperparameters.
- Bootstrap groups come from `complex_group_id` when present, otherwise `pair_id`.

## Required B0a outputs

- `predictions.csv` containing only the untouched test partition;
- `model.joblib`;
- `metadata.json` with hashes, feature names, candidate validation scores, selected C, class counts, and software versions;
- evaluation JSON generated by `evaluate_predictions.py`.

## Interpretation

- High pair-random performance with low C3 performance indicates node/sequence-family memorization.
- High B0a C3 performance requires a shortcut audit before celebrating biological signal.
- B2 must be compared with B0b, not merely B0a, for the primary structural-representation claim.
